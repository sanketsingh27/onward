Cloudflare platform

Worker: A serverless function running on Cloudflare's edge network that answers HTTP requests, scheduled events, and queue messages. This whole folder is one Worker. Avoid: lambda, server.

Binding: A named, typed connection from a Worker to a Cloudflare resource (a database, an AI model, a queue). Declared in wrangler.jsonc, reached in code as env.<NAME>. Avoid: env var, service.

D1: Cloudflare's serverless SQLite database, queried over the network. BOARD_DB and APP_DB are two D1 databases.

Workers AI: Cloudflare's hosted inference API. Runs embedding and text-generation models via env.AI.run(model, input).

Vectorize: Cloudflare's vector index. Stores vectors, returns the closest matches to a query vector.

Queue: Cloudflare's asynchronous message queue. A producer sends a message; a queue() handler consumes it later.

Hono: A small web framework that maps HTTP method + path to a handler, built on the standard Fetch API. Avoid: Express, router.

Job matching

Board: A source of job postings — one company's Ashby feed, tracked in the boards table.

Opening: One normalized job posting — a row in the openings table.

Ingest: Fetch a board's feed, normalize its jobs, write them into openings. The first stage of the pipeline.

Profile: A user's preferences — remote, locations, comp floor, seniority, employment type, exclude terms — stored as JSON in profile.filters.

Hard filter: The rule-based pass that drops openings failing a profile test (remote, location, comp, seniority, employment). Exclude-terms flag an opening but do not drop it.

Embedding: A fixed-length list of numbers (a vector) that stands for a text's meaning; similar texts get similar vectors.

Vector: A list of numbers — an embedding stored in or queried from Vectorize.

Cosine similarity: A −1…1 measure of how aligned two vectors are. Here it is the raw match score between the resume and an opening.

fit: The integer 0–100 on each opening, equal to round(cosine_similarity × 100). Higher is a closer match.

reason: A one-sentence, LLM-written explanation of why a candidate matches an opening.

state: A per-(user, opening) status — saved, applied, or dismissed.
