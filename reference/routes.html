HTTP routes

Method + path Input Calls Returns
GET /health — — { ok: true }
GET /boards — BOARD_DB SELECT board rows
GET /openings — APP_DB SELECT openings (fit > 0, by fit)
GET /openings/ranked ?user= APP_DB SELECT + state openings, minus applied/dismissed
POST /ingest — ingestBoards outcomes [{board, ok, openings, error?}]
PUT /state {user_id, opening_id, status} upsertState { ok: true } or 400
GET /state ?user= listState state rows
POST /embed {texts: string[]} embedTexts (Workers AI) { data: number[][] }
POST /score — scoreSurvivors { scored: n } or 500
POST /reason {resume, title, description?} generateReason (LLM) { reason } or 500
POST /rank {resume, topN?} rankOpenings { ranked: n }
POST /scan {userId?} SCAN_QUEUE.send { jobId }
GET /scan/:id :id path param APP_DB scans SELECT scan row, or {error:'not found'}

Non-HTTP entry points

queue(batch) Consumer for SCAN_QUEUE. Marks a scan running, runs runScan, marks done/error.
scheduled() Cron (0 9 * * *, 9am daily). Sends {jobId, userId:1} to the queue.
