Distinguish ranking by stored fit from generating a reason, and trace the prompt sent to the Llama model.

POST /reason: one reason on demand

const body = await c.req.json<{
  resume?: string; title?: string; description?: string
}>()
if (!body.resume || !body.title) return c.json({ error: 'missing resume or title' }, 400)
const reason = await generateReason(c.env.AI, body.resume, body.title, body.description ?? '')
return c.json({ reason })

This route is useful as a focused operation: the caller supplies a resume and one job. It validates the two required fields, allows an empty description, and returns the generated sentence.

Prompt construction

const messages = [
  { role: 'system', content:
    'You write one-sentence, plain-spoken reasons a candidate matches a job. Be specific, no marketing words.' },
  { role: 'user', content:
    `Resume:\n${resume}\n\nJob: ${title}\n${description}\n\nOne sentence on how well this candidate matches:` },
]
const res = await ai.run(LLM_MODEL, { messages, max_tokens: 80 })
return (res as { response: string }).response.trim()

The system message sets the output style. The user message supplies the evidence. max_tokens: 80 is a bounded output budget; trim() removes whitespace around the model response. The code treats the Workers AI response as { response: string }.

POST /rank: batch the top fit rows

const { results } = await env.APP_DB.prepare(
  'SELECT id, title, description_plain FROM openings ORDER BY fit DESC LIMIT ?',
).bind(topN).all()
for (const o of results) {
  const reason = await generateReason(env.AI, resume, o.title, o.description_plain)
  await stmt.bind(reason, o.id).run()
}
return results.length

/rank does not calculate similarity. It trusts the current fit ordering, selects the requested top N (default 10), generates a reason for each, and persists it in openings.reason. The loop is sequential, so each model call finishes before the next begins.

Two kinds of truth

fit is a numeric retrieval signal from the embedding space. reason is generated prose intended to help a human inspect that signal. The reason should explain the score, not silently redefine the ranking.
