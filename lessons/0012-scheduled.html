The scheduled handler: a daily refresh

The same scan queue can be triggered by a cron schedule instead of a user request.

GlossaryPipeline← Previous↺ Course start
Your win

Explain how wrangler.jsonc schedules a daily event, why the scheduled handler sends to the queue rather than calling runScan directly, and how this completes the system map.

The configuration

"triggers": { "crons": ["0 9 * * *"] }

This cron expression means 9:00 every day, using the configured schedule's timezone semantics. Cloudflare invokes the exported scheduled method at that time. It is not an HTTP request, so Hono routes are not involved.

The handler

async scheduled(_controller: ScheduledController, env: Env) {
  await env.SCAN_QUEUE.send({
    jobId: crypto.randomUUID(),
    userId: 1,
  })
}

It creates a message with the same shape as POST /scan and sends it to the same queue. The scheduled path does not duplicate the scan pipeline. The queue consumer remains the one place that calls runScan, updates statuses, and handles failures.

Three ways into the same work

  • Manual HTTP: POST /scan creates a job and returns its ID.
  • Automatic cron: scheduled creates a job for user 1 at 9am.
  • Queue consumer: receives either message and runs the same runScan.

This is an example of an architectural seam: different triggers share one orchestration function. A future authenticated user trigger or admin action can enqueue work without copying ingestion, filtering, embedding, scoring, or ranking logic.

The complete mental model

The API surface now has a clear division: read configuration (/boards), read results (/openings), refresh data (/ingest), expose model primitives (/embed, /score, /reason, /rank), enqueue the complete workflow (/scan), inspect progress (/scan/:id), and preserve human decisions (/state). The daily schedule is simply another producer.

Course synthesis

The design combines deterministic constraints with semantic retrieval and generated explanation: filter what cannot match, compare what remains, then explain the shortlist. The queue makes the full sequence operationally safe to run away from the request path.
